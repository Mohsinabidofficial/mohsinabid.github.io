# Mohsin Abid – Professional Portfolio

Clean static version of the portfolio website, ready for **GitHub Pages**.

## Live Demo
After enabling GitHub Pages, your site will be available at:  
`https://your-username.github.io/repository-name`

## Files
- `index.html` – Main portfolio page
- `style.css` – All styles
- `README.md` – This file

## How to Deploy on GitHub Pages

1. Create a new repository on GitHub (recommended name: `mohsin-abid-portfolio` or `yourusername.github.io`)
2. Upload these files to the repository
3. Go to **Settings → Pages**
4. Under **Source**, select branch `main` and folder `/ (root)`
5. Click **Save**
6. Wait 1–2 minutes — your site will be live!
